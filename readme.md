<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Snowballs Freeze Mobs is a minimalistic configurable mod which makes it so that hitting a mob with a snowball will result in it being frozen.</span></p>
